2. Memuat dataset CIFAR-10¶

CIFAR-10 tersedia pada tf.keras.datasets. Fungsi load_data() mengembalikan data training dan testing.

Setiap gambar berukuran 32 × 32 piksel dengan 3 kanal warna (RGB). Label dataset berbentuk angka 0 sampai 9. Kita ubah label menjadi array satu dimensi menggunakan squeeze() agar sesuai dengan proses klasifikasi.

In [2]:
# Memuat dataset CIFAR-10
(train_images, train_labels), (test_images, test_labels) = tf.keras.datasets.cifar10.load_data()

# Mengubah label dari bentuk (jumlah_data, 1) menjadi (jumlah_data,)
train_labels = train_labels.squeeze()
test_labels = test_labels.squeeze()

# Nama 10 kelas CIFAR-10
class_names = [
    "Pesawat", "Mobil", "Burung", "Kucing", "Rusa",
    "Anjing", "Katak", "Kuda", "Kapal", "Truk"
]

print("Jumlah data training:", train_images.shape[0])
print("Jumlah data testing :", test_images.shape[0])
print("Bentuk gambar       :", train_images.shape[1:])
print("Bentuk label        :", train_labels.shape)

Normalisasi membantu proses pelatihan karena skala nilai input menjadi lebih kecil dan seragam.

5. Membuat model Neural Network¶

Model dibuat menggunakan Sequential, yaitu susunan layer yang dijalankan secara berurutan.

Arsitektur model:

  • Flatten: mengubah gambar berukuran 32 × 32 × 3 menjadi satu vektor berisi 3.072 nilai.
  • Dense(256, relu): hidden layer pertama dengan 256 neuron.
  • Dropout(0.3): menonaktifkan sebagian neuron secara acak saat training untuk membantu mengurangi overfitting.
  • Dense(128, relu): hidden layer kedua dengan 128 neuron.
  • Dense(10, softmax): output layer dengan 10 neuron, satu untuk setiap kelas CIFAR-10.

Model ini adalah fully connected Neural Network, bukan CNN. Karena itu, gambar diratakan menjadi vektor sebelum diproses.

In [5]:
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Flatten, Dense, Dropout

model = Sequential([
    Input(shape=(32, 32, 3)),
    Flatten(),
    Dense(256, activation="relu"),
    Dropout(0.3),
    Dense(128, activation="relu"),
    Dense(10, activation="softmax")
])

model.summary()

Model: "sequential"

6. Mengompilasi dan melatih model¶

Sebelum training, model dikompilasi dengan:

  • Optimizer Adam: memperbarui bobot model selama pembelajaran.
  • Loss sparse categorical crossentropy: menghitung kesalahan prediksi untuk label berbentuk angka kategori.
  • Metric accuracy: mengukur persentase prediksi yang benar.

Model dilatih selama 10 epoch. validation_split=0.1 menggunakan 10% dari data training sebagai data validasi.

In [6]:
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)

history = model.fit(
    train_images,
    train_labels,
    epochs=10,
    batch_size=64,
    validation_split=0.1
)

7. Evaluasi model¶

Setelah training, model diuji menggunakan data testing yang tidak digunakan untuk memperbarui bobot model.

test_loss menunjukkan nilai kesalahan model, sedangkan test_accuracy menunjukkan proporsi prediksi yang benar pada data testing.

In [7]:
test_loss, test_accuracy = model.evaluate(test_images, test_labels, verbose=2)

print(f"Test loss     : {test_loss:.4f}")
print(f"Test accuracy : {test_accuracy:.4f}")
print(f"Test accuracy : {test_accuracy * 100:.2f}%")

8. Visualisasi accuracy dan loss¶

Grafik training dan validation membantu melihat perubahan performa model selama 10 epoch.

  • Accuracy yang meningkat menunjukkan semakin banyak data yang diprediksi dengan benar.
  • Loss yang menurun menunjukkan kesalahan prediksi semakin kecil.
  • Jika training accuracy terus naik tetapi validation accuracy tertinggal atau menurun, model mungkin mengalami overfitting.

9. Melakukan prediksi pada gambar testing¶

Model menghasilkan 10 probabilitas untuk setiap gambar. argmax() mengambil indeks dengan probabilitas tertinggi sebagai kelas prediksi.

Di bawah ini ditampilkan 25 gambar uji, label prediksi, dan label sebenarnya. Warna judul hijau berarti prediksi benar, sedangkan merah berarti prediksi salah.

In [9]:
predictions = model.predict(test_images[:25], verbose=0)

plt.figure(figsize=(12, 12))

for i in range(25):
    predicted_label = int(np.argmax(predictions[i]))
    actual_label = int(test_labels[i])

    plt.subplot(5, 5, i + 1)
    plt.xticks([])
    plt.yticks([])
    plt.grid(False)
    plt.imshow(test_images[i])

    color = "green" if predicted_label == actual_label else "red"
    plt.xlabel(
        f"Prediksi: {class_names[predicted_label]}\nAsli: {class_names[actual_label]}",
        color=color
    )

plt.tight_layout()
plt.show()
